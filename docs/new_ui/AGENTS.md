# Modern UI documentation

- Maintain Modern UI design and migration notes under `docs/new_ui` on branch `0.3`.
- Put desktop menus in `desktop/<menu>/`; training camps use `desktop/trainingcamp/`.
- Record the source revision, visible data, interactions and outstanding engine decisions.
- Clearly distinguish the HTML prototype, a native RmlUI implementation and engine behaviour.
- Update the relevant document with each substantive UI change and link it from the index.
- Fixed UI artwork, including training-camp maps and illustrations, belongs to the GUI resource set, not the OBW world. Follow `assets.md`; never require stock GUI pictures in a world's asset index.
- Use German for these user-facing design notes. Keep proprietary reference assets out of this repository.
