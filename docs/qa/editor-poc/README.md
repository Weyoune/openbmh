# Native editor POC — QA evidence

All images here contain **synthetic demo data and project-owned geometric
artwork**. No real club, player photograph, original game screen, imported game
artwork, local filesystem path or MCP credential is included. These exact
reviewed image hashes are allowlisted by the public-tree check.

Environment: Debian 13 x86-64; actual SDL2/OpenGL/RmlUI window inside Xvfb,
software OpenGL requested with `LIBGL_ALWAYS_SOFTWARE=1`; 1440×900 window.
These are native application captures, not HTML/browser mockups.

Validation performed:

- `editor_core_tests`: 59 assertions for edit/rollback, revision conflicts,
  references, dates/scales, roster moves/swaps/order, shared undo/redo/save
  checkpoint, atomic OBW overwrite, exact image originals, arbitrary SVG/raster
  transforms, unknown-extension preservation and authenticated MCP HTTP.
  Individual image edits also verify that shared fallback images and other
  records remain unchanged.
  Windows additionally checks a profile directory containing non-ASCII letters.
- `tests/editor_gui_smoke.py`: real mouse/keyboard inspector edit; untouched
  JSON colour field retained; native search focus; shared MCP/native undo/redo;
  save to OBW. This check caught and fixed RmlUI textarea entity handling and
  select-initialization refresh loops.
- Private local checks, whose data is not published here: raw BMH and raw
  Football Limited import, existing converted Classic OBWs, save/reopen, frozen
  Classic portrait composition, and the large private merged 32-league world.
  Structural checks passed; missing biographies/source conflicts remain
  explicit warnings.
- Manifest/table JSON schemas checked against the private Classic-derived and
  merged-world outputs. This is separate from runtime reference/range checks.

Reproduce the synthetic view from a configured build:

```sh
OpenBMHEditor --demo --page clubs --screenshot clubs.png --quit-after-ms 1800
```

The synthetic data is generated by `World::demo()`, not a career save. Options
files used for captures are local QA profiles and are not included. The vector
portrait uses a blue rectangle, a circular head and a rounded shoulder shape;
it is an image-editor fixture, not a real or AI-generated player.

Windows x64/macOS ARM64 build and core/MCP checks are run by the separate
**OBW Editor POC** workflow. A CI pass is not a human GUI acceptance test on
either platform.
